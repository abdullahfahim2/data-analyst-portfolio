# 📊 Data Analyst Portfolio Website

A clean, modern, and responsive portfolio website designed for a **Data Analyst** to professionally showcase their profile, skills, and projects. This site is fully responsive and built using **HTML** and **Tailwind CSS**, optimized for both desktop and mobile users.

## ✅ Features

- 📱 **Responsive Design** — Optimized for mobile, tablet, and desktop screens.
- 🧑‍💼 **Professional Introduction Section** — Clear overview of the client's role and expertise.
- 💼 **Project Portfolio** — Highlights real-world projects with context and visuals.
- 📊 **Skills Showcase** — Lists tools, programming languages, and analytical skills.
- 🌐 **Social Media Integration** — LinkedIn and GitHub profiles are easily accessible.
- 📨 **Contact Section** — Includes a contact form or direct email options.
- 🎯 **Call to Action Buttons** — Encourage hiring or networking.
- ⚡ **Performance Optimized** — Fast-loading pages with clean, semantic HTML.
- 🖼️ **Modern Design Aesthetic** — Clean layout with elegant typography and visuals.
